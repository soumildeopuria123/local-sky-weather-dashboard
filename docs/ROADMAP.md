# Roadmap

Ideas that fit the current small, dependency-free design:

- Add an Auto theme option that follows the device or local sunrise/sunset.
- Add a secure password-reset flow with email delivery.
- Offer an optional hourly forecast strip and weather alerts.
- Add an export/import option for a user's saved cities and settings.
- Add more automated browser checks for the responsive layouts and theme switch.
- Improve hosted rate limiting and abuse protection before wider public use.
