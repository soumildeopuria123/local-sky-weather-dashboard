# Changelog

## 1.0.0 — 2026-11-08

- Live Open-Meteo weather, geocoding, forecasts and a labelled offline fallback.
- Local Node server and Cloudflare Worker/D1 deployment paths.
- Account sign-up, sign-in, server-side sessions and per-account saved cities.
- Illustrated sign-in page with password visibility controls, a strength meter,
  Caps Lock feedback and optional remembered email.
- Day/night dashboard themes with a saved preference and matching world maps.
- Responsive layouts for phones and desktop.
- Automated tests for weather, accounts, API routes and session isolation.
